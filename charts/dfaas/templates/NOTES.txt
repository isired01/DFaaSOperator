{{- else }}

  kubectl apply -f /tmp/dfaas-{{ .Chart.Version }}/dfaas/crds/
{{- end }}

{{- if .Values.ui.enabled }}

The UI has no authentication: anyone who reaches it can read every Environment,
node SSH passwords included, and create or delete Environments and LoadTests.
Keep it on a trusted network, or install with --set ui.service.type=ClusterIP
and use kubectl port-forward.

Open the UI:
{{- if eq .Values.ui.service.type "NodePort" }}
  http://<any-node-ip>:{{ .Values.ui.service.nodePort | default "<assigned-nodeport>" }}/

  kubectl -n {{ .Values.ui.namespace }} get svc {{ include "dfaas.fullname" . }}-ui
{{- else }}
  kubectl -n {{ .Values.ui.namespace }} port-forward svc/{{ include "dfaas.fullname" . }}-ui {{ .Values.ui.service.port }}:{{ .Values.ui.service.port }}
  open http://localhost:{{ .Values.ui.service.port }}
{{- end }}
  {{- if .Values.ui.ingress.enabled }}

Or via Ingress:
  http://{{ .Values.ui.ingress.host }}/
  {{- end }}
{{- end }}
